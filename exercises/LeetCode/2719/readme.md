# 2719. 统计整数数目

## 描述

给你两个数字字符串 `num1` 和 `num2` ，以及两个整数 `max_sum` 和 `min_sum` 。如果一个整数 `x` 满足以下条件，我们称它是一个好整数：

- `num1 <= x <= num2`
- `min_sum <= digit_sum(x) <= max_sum`.

请你返回好整数的数目。答案可能很大，请返回答案对 $10^{9} + 7$ 取余后的结果。

注意，`digit_sum(x)` 表示 `x` 各位数字之和。

## 样例
### 示例 1

```
输入：num1 = "1", num2 = "12", min_num = 1, max_num = 8
输出：11
解释：总共有 11 个整数的数位和在 1 到 8 之间，分别是 1,2,3,4,5,6,7,8,10,11 和 12 。所以我们返回 11 。
```

### 示例 2

```
输入：num1 = "1", num2 = "5", min_num = 1, max_num = 5
输出：5
解释：数位和在 1 到 5 之间的 5 个整数分别为 1,2,3,4 和 5 。所以我们返回 5 。
```

## 限制

- $1 \le num1 \le num2 \le 10^{22}$
- `1 <= min_sum <= max_sum <= 400`


## [思考](code.cpp)
思路并不是很清晰，代码写得非常乱。

主要问题：为了保证搜索中满足$num1 \le now \le num2$，在状态中引入了两个无用的bool变量。

这导致状态数增加了4倍，而且写代码的时候脑子并不是很清醒不知道为什么用了map来写记忆化。
综合导致性能非常差。

## [题解](TODO)
题解主要是考虑：
1. 将问题从`solve(num1, num2)`转化为`solve(1, num2) - solve(1, num1)`。这样就消除了判断下界的需要。
2. 每个数位都和上界`num`一致的状态们实际上只会被用到一次，所以不需要记忆化。

这样就把记忆化的状态减少到了`[num_digit][max_sum]`。
