## 描述

实现一个函数`vector<uint8_t> f(vector<uint8_t>)`，
使得对于任意数组a和b，若有 a < b，则有 f(a) > f(b)。
数组的大小比较方式为“字典序”。

## 思考

题目中的`vector<uint8_t>`实际上相当于`string`，
字符的范围为0~255，
考虑将字符串视为257进制小数，字符0~255对应数字1~256；
则有`f(x) = 1-x`。
考虑反向将f(x)映射为字符串，由于使用了257进制小数，数位上可能出现0~256，
因此采用两位编码：
数字0 => '0 0', 1 => '0 1', 2 => '0 2', ... , 256 => '1 0'；
即每个小数位对应两位字符。
